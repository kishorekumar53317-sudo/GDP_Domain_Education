# EduGuide-AI 🎓🤖

EduGuide-AI is an AI-powered educational platform designed to help students learn smarter, understand difficult concepts, and get instant academic guidance through an AI Tutor.

## 🚀 Features

- 🏠 Interactive Home Page
- 🤖 AI Tutor for academic questions
- 💡 Simple concept explanations
- 📝 Question solving assistance
- 🎯 Personalized learning guidance
- 🔐 Secure Login and Sign Up
- 📚 Exam preparation support
- 📱 Responsive and user-friendly interface

## 🛠️ Technologies Used

### Frontend
- HTML
- CSS
- JavaScript

### Authentication
- Firebase Authentication

### AI & Backend
- Gemini API
- Node.js
- Express.js

## 📂 Project Structure

EduGuide-AI/
- index.html – Home
- features.html – Features
- about.html – About
- login.html – Login
- signup.html – Sign Up
- ai.html – AI Tutor
- css/style.css – Website styling
- js/firebase-auth.js – Firebase authentication
- js/firebase-config.js – Firebase configuration
- js/ai.js – AI Tutor functionality
- server/server.js – Gemini AI backend
- server/package.json – Backend dependencies
